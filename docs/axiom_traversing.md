# 导线测量正向模型公理 (Axiom: Traversing Forward Model)

> 本文档建立从度盘读数/斜距到平面坐标传递的最小数学契约。所有后续代码实现必须严格遵守这些公理。

## 符号约定

| 符号 | 含义 | 单位 (内部存储) |
|------|------|----------------|
| `X_i, Y_i` | 第 i 点的平面坐标 | m |
| `H_i` | 第 i 点的高程 | m |
| `alpha_i` | 第 i 边的坐标方位角 | rad |
| `beta_i` | 第 i 站的水平角 (左角/右角) | rad |
| `D_i` | 第 i 边的水平距离 (平距) | m |
| `S_i` | 第 i 边的斜距 | m |
| `Z_i` | 天顶距 | rad |
| `L, R` | 盘左/盘右水平度盘读数 | rad |
| `2C` | 两倍视准轴误差 | rad |
| `h_inst, h_prism` | 仪器高/棱镜高 | m |
| `L_0` | 度盘零位偏移 | rad |
| `rho` | 弧度-角秒转换 = 206265 | "/rad |
| `n` | 导线边数 (站数) | - |

内部存储一律使用 SI 单位 (米, 弧度), 仅输出时转换为度分秒/毫米。

## A1: 方位角递推 (核心导出量 - 角度)

### A1.1 由坐标反算方位角

```
dx_i = X_i - X_{i-1}
dy_i = Y_i - Y_{i-1}
alpha_i = atan2(dy_i, dx_i)              (A1.1)
```

注: `atan2` 返回值域 (-pi, pi], 需规范化到 [0, 2*pi)。

### A1.2 由方位角递推水平角

**左角定义** (前进方向左侧):

```
beta_i = alpha_{i+1} - alpha_i + pi      (A1.2L)
```

**右角定义** (前进方向右侧):

```
beta_i = alpha_i - alpha_{i+1} + pi      (A1.2R)
```

以上结果均需 mod 2*pi 归化到 [0, 2*pi)。

**断言**: 左角/右角定义必须在项目启动时锁定, 全程不可混用。

### A1.3 方位角正向递推

已知起始边方位角 `alpha_0`, 由水平角递推:

**左角**:
```
alpha_i = alpha_{i-1} + beta_i - pi      (A1.3L)
```

**右角**:
```
alpha_i = alpha_{i-1} - beta_i + pi      (A1.3R)
```

以上结果 mod 2*pi。

## A2: 坐标增量计算 (核心导出量 - 距离)

### A2.1 由坐标反算平距

```
D_i = sqrt((X_i - X_{i-1})^2 + (Y_i - Y_{i-1})^2)   (A2.1)
```

### A2.2 由方位角和平距正向推算坐标

```
dx_i = D_i * cos(alpha_i)                (A2.2)
dy_i = D_i * sin(alpha_i)                (A2.3)
X_i = X_{i-1} + dx_i                     (A2.4)
Y_i = Y_{i-1} + dy_i                     (A2.5)
```

### A2.3 闭合差 (附合导线)

方位角闭合差:

```
f_beta = alpha_n_computed - alpha_n_known  (A2.6)
```

其中 `alpha_n_computed` 由递推得到, `alpha_n_known` 由终点坐标反算。

坐标增量闭合差:

```
f_x = SUM(dx_i) - (X_end - X_start)      (A2.7)
f_y = SUM(dy_i) - (Y_end - Y_start)      (A2.8)
f_D = sqrt(f_x^2 + f_y^2)                (A2.9)
K   = f_D / SUM(D_i)                     (A2.10)
```

**断言**: 数学真值假设下, `f_beta = 0, f_x = 0, f_y = 0, K = 0`。

## A3: 斜距-平距投影 (高程维度)

### A3.1 天顶距与竖直角

天顶距 Z: 从天顶 (正上方) 到目标方向的夹角。
竖直角 v: 从水平面到目标方向的夹角。

```
v = pi/2 - Z                             (A3.1)
```

### A3.2 斜距到平距

```
D = S * sin(Z) = S * cos(v)              (A3.2)
```

### A3.3 高差计算 (三角高程)

```
dH = S * cos(Z) + h_inst - h_prism       (A3.3)
```

或等价:

```
dH = D * cot(Z) + h_inst - h_prism       (A3.4)
```

注: 严格公式还需加入地球曲率和大气折光改正, 短边 (< 500m) 可忽略。

## A4: 方向观测法 (角度读数分解)

### A4.1 盘左/盘右与方向值

设某方向的真值为 `L_bar` (归零后的方向值), 度盘零位偏移为 `L_0`:

```
L = L_0 + L_bar + delta                  (A4.1)
R = L_0 + L_bar - delta + pi             (A4.2)
```

其中 `delta` 为 2C 误差的一半。

### A4.2 2C 计算

```
2C = L - (R - pi) = 2 * delta            (A4.3)
```

规范化: 若 `L - (R - pi)` 超出 (-pi, pi], 需加减 2*pi。

### A4.3 方向值计算

```
L_bar = (L + R - pi) / 2 - L_0          (A4.4)
```

归零后方向值 = 各方向 L_bar - 零方向 L_bar

### A4.4 半测回角值

**盘左半测回**:
```
beta_L = L_bar_fore_L - L_bar_back_L     (A4.5)
```

**盘右半测回**:
```
beta_R = L_bar_fore_R - L_bar_back_R     (A4.6)
```

### A4.5 一测回角值

```
beta_set = (beta_L + beta_R) / 2         (A4.7)
```

**检核**: `|beta_L - beta_R|` <= 半测回较差限差

### A4.6 多测回平均

```
beta_final = mean(beta_set_j, j=1..m)    (A4.8)
```

**检核**: 各测回间 `|beta_set_j - beta_set_k|` <= 方向值较差限差

## A5: 度盘配置

m 个测回, 第 j 测回的零方向度盘配置:

```
L_0_j = (pi / m) * (j - 1) + offset     (A5.1)
```

其中 `offset` 为一个小的固定偏移 (如 2'30" 约 0.000727 rad), 避免各测回零方向读数恰好为 0。

示例 (2 测回):
- 第 1 测回: L_0 ≈ 0°02'30" ≈ 0.000727 rad
- 第 2 测回: L_0 ≈ 90°02'30" ≈ 1.571523 rad

## A6: 距离观测 (EDM)

### A6.1 一测回多次读数

```
S_mean = mean(S_k, k=1..3)               (A6.1)
```

**检核**: `max(S_k) - min(S_k)` <= 读数差限差

### A6.2 往返测

```
D_forward = S_mean_forward * sin(Z_forward)   (A6.2)
D_backward = S_mean_backward * sin(Z_backward) (A6.3)
D_final = (D_forward + D_backward) / 2        (A6.4)
```

**检核**: `|D_forward - D_backward|` <= 往返较差限差

## A7: 核空间约束 (逆向构造的核心条件)

### A7.1 角度核空间 (两层约束)

**第一层: 单方向扰动**

对方向 j 的盘左 L 和盘右 R 施加同向等量扰动 `delta_j`:

```
L_j' = L_j + delta_j                     (A7.1)
R_j' = R_j + delta_j                     (A7.2)
```

效果:
- 方向值变为 `L_bar_j + delta_j` (方向值改变 delta_j)
- 2C 不变: `2C' = L_j' - (R_j' - pi) = 2C_j`

**第二层: 站级约束 (保持水平角不变)**

水平角 = 前视方向值 - 后视方向值。要使水平角不变:

```
beta' = (L_bar_fore + delta_fore) - (L_bar_back + delta_back)
      = beta + (delta_fore - delta_back)
```

**核空间约束**: 同一测站同一测回内, 所有方向施加相同扰动:

```
对所有方向 j: delta_j = delta_station    (A7.3)
```

此时:
- 所有方向值偏移相同量 delta_station
- 水平角不变: `beta' = beta`
- 半测回角值不变, 一测回角值不变
- 2C 不变

**扩展核空间 (允许 2C 在限差内变化)**:

若对 L 和 R 施加不等量扰动, 可引入可控的 2C 变化:

```
L' = L_0 + L_bar + delta_dir + delta_2C/2      (A7.4)
R' = L_0 + L_bar + delta_dir - delta_2C/2 + pi  (A7.5)
```

效果:
- 方向值 = `L_bar + delta_dir`
- 2C' = `delta_2C` (需满足 `|delta_2C|` <= 2C 互差限差)

**水平角不变的约束**: 所有方向的 `delta_dir` 必须相同 (同站同测回)。

### A7.2 距离核空间

斜距 S 和天顶距 Z 的扰动保持平距不变:

```
D = S * sin(Z)
D' = (S + dS) * sin(Z + dZ) = D
```

线性近似:

```
dD ~ sin(Z) * dS + S * cos(Z) * dZ = 0  (A7.5)
```

即:

```
dS/S + cot(Z) * dZ = 0                   (A7.6)
```

当 `Z ≈ pi/2` (接近水平) 时, `cot(Z) ≈ 0`, 需 `dS ≈ 0`。

此时扰动主要通过微调仪器高/棱镜高 (改变 Z) 实现, 斜距扰动需极小。

### A7.3 核空间维度

每方向每测回: 盘左 L, 盘右 R, 构成 2 个标量。方向值方程约束 1 个自由度 (取平均), 剩 1 个自由度 (2C)。

设 m 个测回, k 个方向:
- 总标量: 2mk
- 正向映射的独立输出: k-1 个独立水平角 (由 k 个方向值两两相减)
- 核空间维度: 2mk - (k-1)

```
dim(ker) = 2mk - k + 1                   (A7.6)
```

示例 (2 测回, 3 方向): dim(ker) = 2*2*3 - 3 + 1 = 10

## A8: 正向映射的线性代数结构

### A8.1 坐标空间到核心导出量

从 RTK 平面坐标 `{(X_i, Y_i)}` 到核心导出量:

```
方位角 alpha_i: 唯一确定 (A1.1)
水平角 beta_i: 唯一确定 (A1.2, 左/右角定义锁定后)
平距 D_i: 唯一确定 (A2.1)
```

**关键**: 导线测量的核心导出量可由平面坐标通过纯几何反算唯一确定, 比水准测量更接近可逆映射。

### A8.2 核心导出量到原始读数

从 `{alpha_i, beta_i, D_i}` 到原始读数的映射是多对一:

- 度盘零位 L_0: 每测回 1 维自由参数
- 2C 分配: 每方向每测回 1 维 (在限差内)
- 仪器高/棱镜高: 每站 2 维
- 测距读数分配: 每边每测回 2 维 (3 次读数, 约束均值)

## A9: 逆向构造的人为参数清单

| 参数 | 作用 | 约束范围 | 自由度 |
|------|------|---------|--------|
| 度盘零位 `L_0_j` | 绝对读数基准 | 规范推荐公式 (A5.1) | 每测回 1 维 |
| 左角/右角定义 | 水平角符号与递推 | 离散选择 (必须锁定) | 0 |
| 仪器高 `h_inst` | 斜距-平距-高差分解 | [1.2, 1.6] m | 每站 1 维 |
| 棱镜高 `h_prism` | 同上 | [1.2, 1.6] m | 每站 1 维 |
| 测回数 m | 手簿栏目深度 | 2 (2"级) 或 4 (6"级) | 离散选择 |
| 扰动强度 sigma | 控制模拟真实感 | 匹配目标等级精度 | 全局 1 维 |
