# 误差传播模型 (Error Propagation Model)

> 本文档建立 RTK 噪声到核心导出量的传播公式, 以及模拟数据中核空间扰动的设计规范。

## 符号约定

| 符号 | 含义 | 典型值 |
|------|------|--------|
| `sigma_XY` | RTK 平面精度 | 1-3 cm |
| `sigma_H` | RTK 高程精度 (椭球高) | 2-5 cm |
| `rho` | 弧度-角秒转换 | 206265 "/rad |
| `D` | 导线边长 | 50-500 m |
| `n` | 测站数/边数 | - |
| `sigma_delta` | 核空间扰动标准差 | 依目标等级 |

## A1: RTK 精度基准

RTK 固定解状态下的典型精度 (基线 < 10 km, 开阔环境):

```
平面: sigma_XY = 1 ~ 3 cm
高程: sigma_H  = 2 ~ 5 cm (椭球高)
```

**断言**: 这些数值是不可压缩的物理噪声下限, 构成模拟精度的硬上限。

## A2: 水准测量的 RTK 噪声传播

### A2.1 单站高差噪声

RTK 两点间高差 `h_i = H_i - H_{i-1}`:

```
sigma_dh = sqrt(sigma_H^2 + sigma_H^2) = sqrt(2) * sigma_H    (A2.1)
```

典型值: `sigma_dh ≈ 4.2 cm` (当 sigma_H = 3 cm)

### A2.2 路线闭合差噪声

n 站附合路线, RTK 高程噪声引起的闭合差:

```
sigma_fh = sqrt(n) * sigma_dh = sqrt(2n) * sigma_H            (A2.2)
```

### A2.3 精度匹配判定

| 目标等级 | 闭合差限差 | RTK 噪声 (sigma_H=3cm, n=10) | 判定 |
|---------|-----------|-----------------------------|------|
| 二等 | ±4√L mm (≈12.6mm, L=10km) | ±13.4 cm | 不可 (差1个数量级) |
| 三等 | ±12√L mm (≈37.9mm) | ±13.4 cm | 不可 |
| 四等 | ±20√L mm (≈63.2mm) | ±13.4 cm | 边界 |
| 等外 | ±40√L mm (≈126.5mm) | ±13.4 cm | 可以 |

## A3: 导线测量的 RTK 噪声传播

### A3.1 方位角噪声

RTK 平面误差在边长 D 上引起的方位角噪声。若两点各自独立具有 sigma_XY 误差:

```
sigma_alpha = sqrt(2) * (sigma_XY / D) * rho    (A3.1)
```

若 sigma_XY 已表示为基线相对精度 (如 RTK 标称 "1cm + 1ppm"), 则无需 sqrt(2) 因子。

| 边长 D | sigma_alpha (sigma_XY=2cm, 独立双端) |
|--------|-------------------------------------|
| 50 m   | 116"                                |
| 200 m  | 29"                                 |
| 500 m  | 11.6"                               |
| 1000 m | 5.8"                                |

### A3.2 方位角闭合差噪声

n 条边的导线:

```
sigma_f_beta = sqrt(n) * sigma_alpha        (A3.2)
```

### A3.3 坐标闭合差

RTK 单点平面精度 sigma_XY 在全长 SUM(D) 上:

```
f_D ≈ sigma_XY  (单点误差, 非累积)
K = f_D / SUM(D)                            (A3.3)
```

### A3.4 精度匹配判定

| 目标等级 | 测角中误差 | sigma_alpha (D=200m) | 判定 |
|---------|-----------|---------------------|------|
| 一级 | ≤5" | 20.6" | 不可 |
| 二级 | ≤10" | 20.6" | 不可 |
| 图根 | ≤20"-30" | 20.6" | 长边勉强 |

## A4: 数学真值假设下的扰动设计

### A4.1 核心假设

当我们将 RTK 坐标视为**数学真值** (忽略物理噪声, sigma_XY = sigma_H = 0):

- 核心导出量 (高差, 方位角, 平距) 精确无噪声
- 闭合差 f_h = 0, f_beta = 0, f_x = 0, f_y = 0
- 模拟精度完全由核空间扰动幅度 sigma 控制

**断言**: 在此假设下, 通过控制 sigma 可模拟任意精度等级。扰动幅度 sigma 是人为控制参数, 与 RTK 物理噪声无关。

### A4.2 扰动强度的等级映射

| 目标等级 | 水准 sigma_delta | 导线角度 sigma_delta | 导线距离 sigma_delta |
|---------|-----------------|---------------------|---------------------|
| 二等 | 0.05 mm | 0.5" | 0.5 mm |
| 三等 | 0.5 mm | 2" | 2 mm |
| 四等 | 1.0 mm | 3" | 3 mm |
| 图根 | 2.0 mm | 10" | 10 mm |

### A4.3 扰动分布选择

核空间扰动采样使用截断正态分布:

```
delta ~ N(0, sigma^2), 截断于 [-k*sigma, k*sigma]   (A4.3)
```

其中 k = 2 或 3, 确保扰动不超限。

对于角度 2C: `delta ~ N(0, sigma_2C^2)`, 截断使 `|2*delta|` <= 2C 互差限差。

## A5: 核空间扰动的实施约束

### A5.1 水准测量

扰动必须满足 A7.1-A7.3 (水准公理文档):

```python
# 伪代码: 单面尺扰动
delta = normal(0, sigma_leveling)  # 每站独立采样
a' = a + delta                     # 后视读数
b' = b + delta                     # 前视读数 (同向等量)
assert a' - b' == a - b            # 高差不变
```

### A5.2 导线角度

扰动必须满足 A7.4 (导线公理文档):

```python
# 伪代码: 同一测站所有方向施加相同方向扰动
delta_station = normal(0, sigma_angle)
for direction in all_directions:
    L' = L + delta_station
    R' = R + delta_station
    assert direction_value(L', R') == direction_value(L, R) + delta_station
# 水平角不变 (因为所有方向偏移相同)
```

**注意**: 若要使 2C 在限差内变化, 可对 L 和 R 施加不等量扰动, 但需满足:

```python
L' = L_bar + delta_dir + delta_2C / 2
R' = L_bar + delta_dir - delta_2C / 2 + pi
# 方向值 = L_bar + delta_dir
# 2C = delta_2C
# 要使水平角不变: 所有方向的 delta_dir 必须相同
```

### A5.3 导线距离

扰动必须满足 A7.5-A7.6:

```python
# 伪代码: 斜距-竖直角扰动保持平距不变
dS = normal(0, sigma_distance)

# 数值保护: 当天顶距接近 pi/2 (水平视线) 时, cos(Z) ≈ 0
if abs(cos(Z)) < 1e-6:  # 约 0.02" 以内
    dS = 0               # 斜距几乎不扰动
    dZ = 0               # 主要通过仪器高/棱镜高微调
else:
    dZ = -dS * sin(Z) / (S * cos(Z))   # 由 A7.6 解出

S' = S + dS
Z' = Z + dZ
D' = S' * sin(Z')
assert abs(D' - D) < epsilon        # 平距近似不变
```

当 `Z ≈ pi/2` 时, `cos(Z) ≈ 0`, 公式退化。此时:
- `dS ≈ 0`, 斜距扰动极小
- 主要通过微调仪器高/棱镜高 (改变 Z) 实现扰动

## A6: 前置条件: 高程基准

### A6.1 椭球高与正常高

RTK 输出椭球高 `h_ellipsoid`, 水准测量基于正常高 `H_normal`:

```
H_normal = h_ellipsoid - zeta            (A6.1)
```

其中 `zeta` 为高程异常 (大地水准面差距)。

### A6.2 系统性偏差

高程异常在数公里范围内可达分米级:

```
delta_zeta = zeta_i - zeta_{i-1}         (A6.2)
```

若不进行转换, `delta_zeta` 将作为系统性偏差叠加到每站高差中, 导致闭合差系统性超限。

**断言**: 模拟前必须确认输入高程已转换为正常高, 或假设 zeta 在路线范围内为常数 (短路线近似)。

## A7: 可行性预检公式

在生成模拟数据前, 判定 RTK 精度是否足以模拟目标等级:

### A7.1 水准可行性

```
sigma_dh = sqrt(2) * sigma_H
if sigma_dh > 目标等级每站高差中误差 * 3:
    警告: RTK 高程精度不足以模拟该等级
```

### A7.2 导线可行性

```
sigma_alpha = (sigma_XY / D_min) * rho
if sigma_alpha > 目标等级测角中误差 * 3:
    警告: RTK 平面精度不足以模拟该等级导线
```

### A7.3 数学真值假设下的特殊处理

若用户选择"数学真值假设" (忽略 RTK 物理噪声), 可行性预检跳过, 但必须在输出中标注:

```
"本数据基于数学真值假设模拟生成, 不代表 RTK 实测精度可达目标等级。"
```
