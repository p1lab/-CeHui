# 水准测量正向模型公理 (Axiom: Leveling Forward Model)

> 本文档建立从水准尺读数到点高程传递的最小数学契约。所有后续代码实现必须严格遵守这些公理。

## 符号约定

| 符号 | 含义 | 单位 (内部存储) |
|------|------|----------------|
| `H_i` | 第 i 个点的高程 (正常高) | m |
| `h_i` | 第 i 测站的高差 | m |
| `a_i` | 第 i 站后视读数 | m |
| `b_i` | 第 i 站前视读数 | m |
| `H_sight_i` | 第 i 站视线高 | m |
| `S_back_i`, `S_fore_i` | 第 i 站后/前视距 | m |
| `d_i` | 第 i 站视距差 = S_back - S_fore | m |
| `Sigma_d_i` | 累积视距差 | m |
| `u, l` | 上丝、下丝读数 | m |
| `K` | 红面尺常数 (双面尺) | m |
| `n` | 测站总数 | - |

内部存储一律使用 SI 单位 (米)，仅输出时转换为毫米。

## A1: 基本高差方程 (不可再约核心)

设第 i 站后视点高程为 `H_{i-1}`, 前视点高程为 `H_i`:

```
h_i = a_i - b_i                          (A1.1)
H_i = H_{i-1} + h_i                      (A1.2)
```

**断言**: 这是水准测量中唯一决定高差的方程。所有观测数据的高程信息仅通过此方程传递。

## A2: 视线高模型 (测站内部传递)

第 i 站视线高:

```
H_sight_i = H_{i-1} + a_i                (A2.1)
H_i       = H_sight_i - b_i              (A2.2)
```

**推论**: `a_i - b_i = H_sight_i - H_{i-1} - (H_sight_i - H_i) = H_i - H_{i-1}`, 与 A1 等价。

## A3: 高程链式传递 (附合水准路线)

对于 n 站附合路线, 起点 H_0, 终点 H_n:

```
H_k = H_0 + SUM(h_i, i=1..k)            (A3.1)
H_n = H_0 + SUM(h_i, i=1..n)            (A3.2)
```

闭合差:

```
f_h = SUM(h_i, i=1..n) - (H_n - H_0)    (A3.3)
```

**断言**: 当所有 h_i 精确时, f_h = 0 (数学真值假设下)。

## A4: 视距计算

```
S_i = 100 * (u_i - l_i)                  (A4.1)
d_i = S_back_i - S_fore_i                (A4.2)
Sigma_d_i = Sigma_d_{i-1} + d_i          (A4.3)
```

视距常数 C = 100 (乘常数), 对于大多数光学水准仪成立。

## A5: 双面尺读数关系 (三等/四等)

### A5.1 黑面与红面

黑面读数 (主分划, 零起点): `a_black`, `b_black`
红面读数 (辅分划, K 值起点): `a_red`, `b_red`

```
K + a_black - a_red = delta_a            (A5.1)
K + b_black - b_red = delta_b            (A5.2)
```

其中 `|delta_a|, |delta_b|` 为 K+黑-红 检核差, 应 <= 限差。

### A5.2 高差计算

```
h_black = a_black - b_black                      (A5.3)
h_red   = a_red - b_red - (K_back - K_fore)      (A5.4)
```

注: 红面零点差改正 = -(K_back - K_fore)。推导: 若 red = black + K (即 K+黑-红=0), 则 h_red_raw = h_black + (K_back - K_fore), 需减去改正数得到 h_red = h_black。

### A5.3 高差中数

```
h_mid = (h_black + h_red_corrected) / 2  (A5.5)
```

**检核**: `|h_black - h_red_corrected|` <= 限差

## A6: 基辅分划关系 (二等因瓦尺)

### A6.1 基本分划与辅助分划

```
a_aux = a_basic + C_aux + eps_a          (A6.1)
b_aux = b_basic + C_aux + eps_b          (A6.2)
```

其中 `C_aux` 为基辅分划常数差 (约 3.0155m, 依具体尺型), `eps` 为微小偏差。

**检核**: `|a_basic - a_aux + C_aux|` <= 0.5 mm (基辅读数较差)

### A6.2 高差

```
h_basic = a_basic - b_basic
h_aux   = a_aux - b_aux
```

**检核**: `|h_basic - h_aux|` <= 0.7 mm (基辅高差较差)

## A7: 核空间约束 (逆向构造的核心条件)

核空间中的扰动不改变核心导出量 (高差), 是模拟数据保持数学自洽的根本条件。

### A7.1 单面尺核空间

对第 i 站施加扰动 `(delta_a_i, delta_b_i)`:

```
delta_a_i = delta_b_i = delta_i          (A7.1)
```

**证明**: `(a_i + delta) - (b_i + delta) = a_i - b_i = h_i`, 高差不变。

### A7.2 双面尺核空间 (黑红面同步)

对黑面和红面施加同向等量扰动:

```
delta_a_black = delta_a_red = delta_b_black = delta_b_red = delta_i   (A7.2)
```

**推论**: K+黑-红 检核差不变, 黑红面高差之差不变, 高差中数不变。

### A7.3 基辅分划核空间

```
delta_basic = delta_aux = delta_i        (A7.3)
```

**推论**: 基辅读数差不变, 基辅高差差不变。

### A7.4 视距核空间

视距数据不进入高程计算, 因此:
- 上/下丝读数可任意变化, 只要 `S = 100 * (u - l)` 保持合理
- 视距差 d 和累积差 Sigma_d 须满足规范限差, 但不影响高差

### A7.5 核空间维度

每站原始观测 8 个标量 (双面尺: a_black, a_red, b_black, b_red, u_back, l_back, u_fore, l_fore)。
高差方程仅约束 1 个自由度。

```
dim(ker) >= 8n - n = 7n                  (A7.5)
```

**结论**: 核空间是高维仿射子空间, 逆向构造的解空间无限, 需人为参数锁定。

## A8: 正向映射的线性代数结构

### A8.1 商映射

正向映射 `f: X -> Z` (观测空间 -> 高差空间) 是满射、非单射的线性映射:

```
rank(B) = n  (n 个独立高差)
dim(ker B) = dim(X) - n >= 7n
```

商空间 `X / ker(B) ~ Z ~ R^n`。

### A8.2 信息损失层次

| 层次 | 数据 | 是否进入高程计算 | 损失类型 |
|------|------|-----------------|---------|
| L1 | 读数差 (a-b) | 是 | 无损失 |
| L2 | 绝对读数 a, b | 否 | 损失视线高 |
| L3 | 视距 S | 否 | 完全损失 |
| L4 | 黑红面较差 | 否 | 完全损失 (冗余检核) |
| L5 | 元数据 | 否 | 完全损失 |

## A9: 逆向构造的人为参数清单

从 RTK 高程 `{H_i}` 反演观测数据, 必须人为设定以下参数:

| 参数 | 作用 | 约束范围 | 自由度 |
|------|------|---------|--------|
| `H_sight_i` | 分解后/前视读数 | 使读数在 [0.3, 2.5] m | 每站 1 维 |
| `(S_back_i, S_fore_i)` | 分解上/下丝 | 满足等级视距差限差 | 每站 2 维 (受 1 维差约束, 剩 1 维) |
| 尺型与 K 值 | 黑红面/基辅系统 | 离散选择 | 0 |
| 扰动强度 sigma | 控制模拟真实感 | 匹配目标等级精度 | 全局 1 维 |
